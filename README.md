# ClipCatcher 📋

**ClipCatcher** — это быстрый, легковесный и умный менеджер буфера обмена для Windows. Программа работает в фоновом режиме, сохраняет историю скопированного текста и предоставляет быстрый доступ к ней по одной комбинации клавиш.

---

## ✨ Основные возможности

*   **⚡ Быстрый вызов:** Нажмите `Alt + V` в любом месте системы, чтобы открыть окно истории.
*   **📌 Закрепление (Pin):** Важные записи можно закрепить вверху списка, чтобы они не потерялись.
*   **🔍 Умный поиск:** Мгновенный поиск по всей сохраненной истории буфера.
*   **🔢 Быстрый выбор:** Клавиши от `1` до `9` на клавиатуре автоматически копируют соответствующий элемент и закрывают окно.
*   **🎨 Превью цветов:** Если вы скопируете HEX-код цвета (например, `#0078d7`), программа покажет цветной квадрат рядом с ним.
*   **🎬 Скачивание медиа:** Если в буфер попадает ссылка на YouTube, TikTok или Instagram, появляются кнопки для быстрой загрузки видео или аудио (MP3) прямо в папку `Downloads`.
*   **📁 Работа с путями:** Копирование пути к файлу активирует кнопку быстрого открытия содержащей его папки.
*   **🚀 Автозагрузка:** Программа автоматически прописывается в реестр Windows для запуска при старте системы.

## 🚀 Как установить и запустить

Так как проект распространяется в виде готового приложения, вам не нужно устанавливать Python или сторонние библиотеки.

1. Перейдите в раздел **Releases** (Релизы) на этой странице GitHub.
2. Скачайте актуальную версию файла `ClipCatcher.exe`.
3. Перенесите скачанный файл в любую удобную папку на компьютере (например, в `C:\Program Files\ClipCatcher` или в вашу личную папку приложений).
4. Запустите `ClipCatcher.exe`.

> ℹ️ **После первого запуска:** Программа сразу свернется в системный трей (возле часов). Нажмите `Alt + V`, чтобы открыть главное окно.

## 🛠 Управление и горячие клавиши

| Действие | Как выполнить |
| :--- | :--- |
| **Открыть окно истории** | Нажать `Alt + V` на клавиатуре |
| **Быстро скопировать элемент** | Кликнуть по нему ЛКМ или нажать цифру от `1` до `9` |
| **Контекстное меню** | Кликнуть ПКМ по элементу (Удалить, Закрепить, Открыть ссылку в браузере) |
| **Скрыть окно** | Кликнуть мимо окна или нажать на крестик (программа не закроется, а уйдет в трей) |
| **Полный выход** | Кликнуть ПКМ по иконке в трее -> **Выход** |

## 🎵 Настройка скачивания в MP3 (Установка FFmpeg)

По умолчанию программа сохраняет аудио в том формате, в котором оно хранится на сайте (например, `.m4a` или `.webm`). Чтобы ClipCatcher мог автоматически превращать эти файлы в привычный **.mp3**, ему нужен небольшой бесплатный помощник — **FFmpeg**.

Настроить его нужно всего один раз, это займет полминуты:

1. **Скачайте архив:** Перейдите на сайт с официальными сборками [Gyan.dev FFmpeg](https://www.gyan.dev/ffmpeg/builds/) и в блоке *release builds* кликните по ссылке **ffmpeg-release-essentials.zip** (начнется скачивание ZIP-архива).
2. **Найдите файл:** Откройте скачанный архив, зайдите в самую первую папку, а внутри неё — в папку **bin**. Там вы увидите файл `ffmpeg.exe`.
3. **Перенесите к программе:** Скопируйте файл `ffmpeg.exe` из архива и вставьте его **в ту же папку на вашем компьютере, где лежит `ClipCatcher.exe`**.

> ✨ **Готово!** Больше ничего делать не нужно. Теперь при нажатии на кнопку «🎵 MP3» программа сама перекодирует звук в настоящий MP3-файл и положит его в папку `Downloads`.

## ⚠️ Важная информация по безопасности (Ложные срабатывания)

Для отслеживания глобального сочетания клавиш `Alt + V` программа использует низкоуровневый перехват клавиатуры. Из-за этого некоторые антивирусы (включая встроенный Windows Defender) могут ошибочно помечать приложение как подозрительное (детект вроде *Keylogger* или *Trojan*). 

Это **ложное срабатывание**, стандартное для всех независимых менеджеров буфера обмена. Программа работает локально, сохраняет историю исключительно на вашем компьютере в файл `history.json` рядом с `.exe` и не отправляет никаких данных в сеть. При желании вы можете изучить исходный код в истории коммитов этого репозитория.
